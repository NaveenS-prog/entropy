# Brag Plan: Entropy

## What is this app?
Entropy is an architectural security-debt analyzer for AI-assisted codebases that deterministically scans AST structures for hidden maintenance and security risk without executing repository code.

## The angle
In a world flooded with superficial "AI code detectors" that hallucinate probabilities, Entropy takes a radically honest, engineering-grounded stance: the Non-Attribution Covenant. It never guesses who or what wrote the code. Instead, it measures concrete, observable AST patterns—unauthenticated administrative routes, swallowed exceptions, unvalidated inputs, and secret leaks—and calculates a mathematically sound 0–100 Entropy Debt Score with verbatim code evidence.

## Hook (first 2-3 seconds)
A fast-pulsing terminal scan:
`$ entropy scan .`
"Stop guessing if AI wrote the code. Analyze the architectural debt it leaves behind."

## Key moments (the middle)
- The glowing Entropy Debt Score Badge (`28 / 100 LOW DEBT`) with severity distributions (Critical: 0, High: 2, Medium: 4, Low: 6) counting up on a precision saturation curve.
- The Architectural Debt Categories Breakdown: Authentication Consistency, Error Handling, Input Validation, and Logging & Secrets.
- Verbatim code evidence callout highlighting an exact AST flaw with line-numbered code and zero mock data.

## Outro / punchline
The Engineering Constitution: "Article II — The Non-Attribution Covenant: Zero mock findings. Zero AI probability guesses. Just deterministic architectural truth." Finished with the Entropy mark and GitHub repository link.

## User flow worth showing
`entropy scan .` CLI ingestion (4,250 LOC analyzed) → AST rule evaluation across 7 architectural debt categories → Live Score Banner & Verbatim Evidence breakdown.
